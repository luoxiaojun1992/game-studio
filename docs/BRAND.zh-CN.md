## 1. Logo 标志

![Game Dev Studio Logo](./images/brand/logo.svg)

Logo 以**游戏手柄**为核心图形，左侧为十字方向键，右侧为 AB 功能按钮，外围 8 个光点均匀对称分布代表多智能体协作生态。整体以简洁几何形态与科技感配色传达「AI 驱动的游戏开发平台」品牌语义。

### Logo 图形构成

| 元素 | 说明 |
|------|------|
| 手柄主体 | 圆角矩形（`rx=40`），深蓝渐变（`#1e4470` → `#0a1628`） |
| 十字键 (D-pad) | 左侧十字形方向键，青色（`#4fc3f7`） |
| 功能按钮 | 右侧三个圆形按钮，靛紫/青色交替（`#7c4dff` / `#4fc3f7`） |
| 外围光点 | 8 个点按 45° 间隔均匀分布，主色/辅色交替 |
| ViewBox 画布 | `0 0 480 480` — 正方形比例，矢量可缩放 |

### Logo 版本

当前仅定义**深色主题**标准版本。始终在深色背景（`#050510` 或更暗）上使用。

### 安全留白

Logo 四周保持**不小于 Logo 高度 25%** 的安全留白区域，区域内不得放置文字、图形或 UI 元素。

### 最小尺寸

- **数字场景**：高度 ≥ 32px
- **印刷场景**：宽度 ≥ 15mm

## 2. 标准色值

| 角色 | Hex | 预览 | 用途 |
|------|-----|------|------|
| **背景色** | `#050510` | ████████ | 主深色背景、画布底色 |
| **主色** | `#4FC3F7` | ████████ | 主要强调色、品牌亮点、交互元素 |
| **辅色** | `#7C4DFF` | ████████ | 辅助强调色、次级操作、重点标记 |
| **面板色** | `#0D1B2E` | ████████ | 卡片背景、面板、浮层表面 |
| **边框色** | `#1A3050` | ████████ | 分割线、边框、禁用态 |
| **文本次要色** | `#92A8C0` | ████████ | 次要文本、说明文字、占位符 |

### 配色比例

遵循 **60-30-10** 原则：
- **60%** — 背景色/面板色（深色中性色）
- **30%** — 主色/辅色（品牌强调色）
- **10%** — 点缀与装饰元素

## 3. 字体规范

### 品牌名

| 属性 | 值 |
|------|-----|
| 字体 | **Space Grotesk Bold** |
| 字号 | 56px（标题）— 72px（Hero 大标题） |
| 颜色 | 线性渐变：`#4FC3F7` → `#7C4DFF` |
| 字间距 | 6px |
| 大小写 | 全大写 |

### 标语与正文

| 属性 | 值 |
|------|-----|
| 字体 | **DM Sans Regular** |
| 字号 | 22–24px（标语），16–18px（正文） |
| 颜色 | `#92A8C0`（次要文本）或 `#7899B0`（标语） |

### 字体层级

| 层级 | 字体 | 字号 | 字重 | 颜色 |
|------|------|------|------|------|
| H1 / 品牌名 | Space Grotesk | 56–72px | Bold | 渐变 |
| H2 / 章节标题 | Space Grotesk | 28–36px | Bold | `#4FC3F7` |
| 正文 | DM Sans | 16–24px | Regular | `#92A8C0` |
| 说明/标注 | DM Sans | 14px | Regular | `#5C798F` |

## 4. 使用规范

### ✅ 允许

- 在深色背景（`#050510` 或 `#0D1B2E`）上使用 Logo
- 遵守 25% 安全留白规则
- 在深色表面上使用渐变品牌名
- 保持 Logo 比例一致（不拉伸、不倾斜）
- UI 中以主色（`#4FC3F7`）为主导强调色

### ❌ 禁止

- 在浅色/白色背景上放置 Logo
- 修改 Logo 颜色或比例
- 添加投影、发光或其他特效
- 旋转或翻转 Logo
- 在数字场景中使用小于 32px 的 Logo
- 在安全留白区域内组合其他图形
